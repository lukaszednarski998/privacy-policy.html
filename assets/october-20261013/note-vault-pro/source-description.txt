APP NAME:
NOTE VAULT PRO

SHORT DESCRIPTION:
Private notes with handwriting, encryption and Wear OS sync.

FULL DESCRIPTION:
NOTE VAULT PRO is a private, feature-rich notebook for Android with support for Wear OS. Notes are stored on your device, and no account is required to use the app.

Create and edit notes
Create notes, checklists, tables, code blocks and LaTeX formulas. Add images, PDF documents, audio recordings and other attachments. Write by hand using a pen, pencil, highlighter, eraser, shapes, ruler, triangle and lasso.

Handwriting recognition, document OCR and local dictation help convert content into text. Speech recognition availability depends on the device, Android version and installed language.

Organize your notes
- Folders, subfolders, tags, pinned notes, favorites and archive
- Smart folders and sorting
- Search through titles, content, folders and tags
- Links between notes and backlinks
- Version history, autosave, drafts and Trash
- Recent note tabs, tablet view and a selected-note widget
- Quick actions for notes, checklists, scans, recordings and handwriting

Privacy and protection
Protect selected notes and supported attachments using AES-GCM encryption. Use a PIN, biometric authentication and an app lock. Searching protected notes is available after authentication and runs in memory during the current session.

Reminders
Schedule one-time, daily, weekly, monthly or weekday reminders. Snooze a reminder for 10 minutes or mark it as complete.

Import, export and PDF
Import notes and files, share text with attachments, and export to TXT, Markdown, PDF, HTML or DOCX. Add handwritten vector annotations to existing PDF documents without converting the entire page into an image. Web Clipper saves the text of a selected HTTPS page along with its source.

Backups and Sync PRO
Create manual or automatic backups. Sync PRO synchronizes notes through a folder selected in the Android system file picker. This can be a local folder or one made available by a supported cloud provider. Automatic backups and synchronization are password-protected. The app does not provide its own cloud service.

Phone and Wear OS
Connect NOTE VAULT PRO to a compatible Wear OS watch. Notes sync automatically, or you can start synchronization with the Sync button. When the watch confirms receipt, the progress bar shows a green check mark.

On your watch, browse notes, create and edit text, manage pinned notes, favorites, archived items and protection, and work offline. Note content and organizational data are synchronized. Concurrent edits are preserved as conflict copies. Attachment details are displayed on the watch, and files can be downloaded on demand.

NOTE VAULT PRO contains no ads. Network features are used for synchronization, recognition-model downloads, Google Play purchases and Web Clipper when you choose to use them.

На часах можно просматривать заметки, создавать и редактировать текст, менять состояния закрепления, избранного, архива и защиты, а также работать офлайн. Содержимое и данные организации синхронизируются; одновременные изменения сохраняются как конфликтная копия. Сведения о вложениях видны на часах, файлы загружаются по запросу.

NOTE VAULT PRO не содержит рекламы. Сетевые функции используются для синхронизации, загрузки моделей распознавания, покупок в Google Play или при запуске Web Clipper.

APP NAME:
NOTE VAULT PRO

SHORT DESCRIPTION:
Нотатки для Android і Wear OS: шифрування, рукопис, OCR і синхронізація.

FULL DESCRIPTION:
NOTE VAULT PRO — багатофункціональний застосунок для нотаток на Android, орієнтований на зберігання даних на пристрої. Нотатки зберігаються на пристрої, а для користування застосунком не потрібен обліковий запис.

Створюйте звичайні нотатки, контрольні списки, таблиці, блоки коду та формули LaTeX. Додавайте зображення, PDF-документи, аудіозаписи й інші вкладення. Пишіть від руки пером, олівцем або маркером і використовуйте гумку, фігури, лінійку, косинець і ласо. Розпізнавання рукопису, OCR документів і локальне голосове введення допомагають швидше перетворювати матеріали на текст. Доступність розпізнавання мовлення залежить від пристрою, версії Android і встановленої мови.

• папки й підпапки, теги, закріплені нотатки, вибране та архів,

• швидкі дії для нотатки, списку, сканування, запису та рукопису.

КОНФІДЕНЦІЙНІСТЬ І ЗАХИСТ
Захищайте вибрані нотатки й підтримувані вкладення за допомогою шифрування AES-GCM. Застосунок підтримує PIN-код, біометричну автентифікацію та повне блокування. Пошук у вмісті захищених нотаток доступний після автентифікації та виконується в пам’яті поточного сеансу.

НАГАДУВАННЯ
Налаштовуйте одноразові, щоденні, щотижневі, щомісячні нагадування або нагадування лише в робочі дні. Сповіщення можна відкласти на 10 хвилин або позначити як виконане.

ІМПОРТ, ЕКСПОРТ І PDF
Імпортуйте нотатки й файли, діліться текстом із вкладеннями та експортуйте у TXT, Markdown, PDF, HTML і DOCX. Додавайте рукописні векторні анотації до наявних PDF без перетворення всієї сторінки на зображення. Web Clipper зберігає текст вибраної HTTPS-сторінки разом із джерелом.

РЕЗЕРВНЕ КОПІЮВАННЯ ТА СИНХРОНІЗАЦІЯ
Створюйте резервні копії вручну або автоматично. Sync PRO синхронізує нотатки через папку, вибрану в системному вікні Android. Це може бути локальна папка або папка підтримуваного хмарного провайдера, доступна в системному вікні вибору файлів. Автоматичні копії та синхронізація захищені паролем. Застосунок не керує власною хмарною службою.

ТЕЛЕФОН + WEAR OS
Підключіть застосунок до сумісного годинника Wear OS. Нотатки синхронізуються автоматично, а кнопка «Синхронізувати» запускає процес вручну. Після підтвердження годинником індикатор завершується зеленою позначкою. На годиннику можна переглядати нотатки, створювати й редагувати текст, змінювати стани закріплення, обраного, архіву та захисту, а також працювати офлайн. Вміст і дані організації синхронізуються; одночасні зміни зберігаються як конфліктна копія. Відомості про вкладення видно на годиннику, файли завантажуються на запит.

NOTE VAULT PRO не містить реклами. Мережеві функції використовуються для синхронізації, завантаження моделей розпізнавання, покупок Google Play або під час запуску Web Clipper.
