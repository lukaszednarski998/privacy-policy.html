FILE 2 WATCH - Privacy Policy

Last updated: 7 October 2026
Package: pl.arvion.file2watch
Platform: Android phone + Wear OS
One-time purchase product: full_version

English

Summary: FILE 2 WATCH is designed to let users select files and folders on an Android phone, transfer them to a compatible Wear OS smartwatch, manage received files on the watch, and transfer files from the watch back to the phone. Normal file transfer is device-to-device and does not require a developer-operated cloud storage account.

1. Files and folders selected by the user

FILE 2 WATCH uses Android's system file and folder selection mechanisms to let the user choose files or folders for transfer. The app processes only the content required to perform the action requested by the user.

Selected files and folder structures may be read so they can be queued and transferred to the paired smartwatch. Relative folder paths may be preserved so folder transfers can be recreated correctly on the destination device.

2. Phone-to-watch and watch-to-phone transfer

The app transfers user-selected files between the Android phone and a compatible Wear OS smartwatch. Depending on the selected or available transfer mode, this may use local Wi-Fi communication or Android/Wear OS communication channels.

When a user sends a file from the watch back to the phone, the file may be saved to the phone's Downloads area or another location used by the app for the requested transfer.

3. Transfer metadata and integrity checks

To manage transfers, the app may process technical metadata such as file name, file size, relative path, transfer direction, queue state, progress, completion acknowledgements and cryptographic SHA-256 checksums used to verify file integrity.

This technical information is used to perform and verify transfers and is not intended for advertising or profiling.

4. File management on Wear OS

On the smartwatch, FILE 2 WATCH includes file-management functions for received or locally available files, including creating folders, renaming, moving, deleting and viewing file information. These actions operate on files stored on the user's device.

5. File preview and playback

The smartwatch app can open or preview supported content, including images, audio and video, PDF documents, text-based files and ZIP file listings. The content is processed on the user's device for the requested preview or playback.

6. Network and device communication

Network access may be used for local Wi-Fi transfer and communication between the user's phone and smartwatch. Android/Wear OS platform services may also exchange connection, device and synchronization information needed to establish and maintain the transfer requested by the user.

Users should transfer files only between devices and networks they trust.

7. Trial state and phone-watch synchronization

FILE 2 WATCH includes a 60-minute trial. The app may store local timestamps and entitlement state needed to determine whether the trial is active, expired or unlocked.

The trial and entitlement state may be synchronized between the phone and smartwatch through the Wear Data Layer so that both devices apply a consistent access state.

8. Google Play Billing and one-time purchase

The full version can be unlocked through a one-time Google Play purchase using product ID full_version. Google Play handles payment processing. The developer does not receive the user's payment-card details.

The app may receive purchase and entitlement information needed to verify, acknowledge and restore the purchase. The app derives an entitlement token for phone-watch synchronization; the raw Google Play purchase token is not stored or sent to the smartwatch by FILE 2 WATCH.

9. Storage and retention

Transferred files remain on the user's phone or smartwatch until the user deletes them, moves them, clears application data or uninstalls the app, depending on where the file is stored.

Local queue, transfer, trial, language and entitlement information may remain on the device as needed for app functionality. Users can remove local app data using Android system settings or by uninstalling the application.

10. Sharing of user files

FILE 2 WATCH transfers files only as part of actions initiated by the user between the user's selected devices. The app does not require the user to create a FILE 2 WATCH developer account for normal file transfer.

Platform providers such as Google may independently process technical, account, security, installation, synchronization or transaction information when providing Android, Wear OS, Google Play services or Google Play Billing. Such processing is governed by Google's own terms and privacy policies.

11. Children

FILE 2 WATCH is a general file-transfer utility and is not designed to collect children's personal information. Users should avoid transferring sensitive information unless they understand and trust the destination device and network.

12. Security

The app uses platform communication mechanisms and file-integrity verification as part of its transfer workflow. No electronic storage or wireless communication method can be guaranteed to be completely secure, so users should use trusted devices and networks.

13. Changes to this policy

This policy may be updated when FILE 2 WATCH features, permissions, platform services, purchase behavior or legal requirements change. The current version will be published at this URL with an updated date.

14. Contact

For privacy questions relating to FILE 2 WATCH, use the official developer contact details shown in the Google Play listing or the official developer website: https://lukaszednarski998.github.io/privacy-policy.html/.

Polski

Podsumowanie: FILE 2 WATCH służy do wybierania plików i folderów na telefonie z Androidem, przesyłania ich do zgodnego zegarka Wear OS, zarządzania odebranymi plikami na zegarku oraz przesyłania plików z zegarka z powrotem do telefonu. Standardowy transfer plików odbywa się między urządzeniami i nie wymaga konta ani chmury obsługiwanej przez dewelopera.

1. Pliki i foldery wybrane przez użytkownika

FILE 2 WATCH korzysta z systemowych mechanizmów Androida do wyboru plików i folderów. Aplikacja przetwarza zawartość potrzebną wyłącznie do wykonania operacji zainicjowanej przez użytkownika.

Wybrane pliki i struktura folderów mogą być odczytywane w celu dodania ich do kolejki i przesłania do sparowanego zegarka. Względne ścieżki katalogów mogą być zachowywane, aby prawidłowo odtworzyć strukturę folderów na urządzeniu docelowym.

2. Transfer telefon-zegarek i zegarek-telefon

Aplikacja przesyła wybrane przez użytkownika pliki między telefonem z Androidem a zgodnym zegarkiem Wear OS. W zależności od wybranego lub dostępnego trybu transfer może korzystać z lokalnej sieci Wi-Fi albo kanałów komunikacyjnych Android/Wear OS.

Gdy użytkownik przesyła plik z zegarka z powrotem do telefonu, plik może zostać zapisany w folderze Pobrane telefonu lub w innym miejscu używanym przez aplikację do wykonania żądanej operacji.

3. Metadane transferu i kontrola integralności

Do obsługi transferu aplikacja może przetwarzać dane techniczne, takie jak nazwa i rozmiar pliku, względna ścieżka, kierunek transferu, stan kolejki, postęp, potwierdzenie zakończenia oraz sumy kontrolne SHA-256 używane do sprawdzania integralności pliku.

Te informacje techniczne są wykorzystywane do wykonania i sprawdzenia transferu, a nie do reklamy ani profilowania.

4. Zarządzanie plikami na Wear OS

Na zegarku FILE 2 WATCH udostępnia funkcje zarządzania odebranymi lub lokalnie dostępnymi plikami, w tym tworzenie folderów, zmianę nazwy, przenoszenie, usuwanie i wyświetlanie informacji o pliku. Operacje te dotyczą plików zapisanych na urządzeniu użytkownika.

5. Podgląd i odtwarzanie plików

Aplikacja na zegarku może otwierać lub wyświetlać obsługiwane treści, w tym obrazy, audio i wideo, dokumenty PDF, pliki tekstowe oraz listę zawartości archiwów ZIP. Treść jest przetwarzana na urządzeniu użytkownika w celu wykonania żądanego podglądu lub odtwarzania.

6. Sieć i komunikacja między urządzeniami

Dostęp do sieci może być używany do lokalnego transferu Wi-Fi i komunikacji między telefonem a zegarkiem użytkownika. Usługi platformy Android/Wear OS mogą również wymieniać informacje o połączeniu, urządzeniu i synchronizacji potrzebne do nawiązania oraz utrzymania transferu zainicjowanego przez użytkownika.

Pliki należy przesyłać wyłącznie między zaufanymi urządzeniami i w zaufanych sieciach.

7. Trial i synchronizacja stanu telefon-zegarek

FILE 2 WATCH zawiera 60-minutowy trial. Aplikacja może lokalnie przechowywać znaczniki czasu oraz stan uprawnienia potrzebne do ustalenia, czy trial jest aktywny, zakończony czy aplikacja została odblokowana.

Stan trialu i uprawnienia może być synchronizowany pomiędzy telefonem i zegarkiem przez Wear Data Layer, aby oba urządzenia stosowały spójny stan dostępu.

8. Google Play Billing i zakup jednorazowy

Pełną wersję można odblokować poprzez jednorazowy zakup Google Play o identyfikatorze produktu full_version. Płatność jest obsługiwana przez Google Play. Deweloper nie otrzymuje danych karty płatniczej użytkownika.

Aplikacja może otrzymywać informacje o zakupie i uprawnieniu potrzebne do weryfikacji, potwierdzania oraz przywracania zakupu. FILE 2 WATCH tworzy token uprawnienia używany do synchronizacji telefon-zegarek; surowy token zakupu Google Play nie jest zapisywany ani wysyłany na zegarek przez FILE 2 WATCH.

9. Przechowywanie i usuwanie danych

Przesłane pliki pozostają na telefonie lub zegarku użytkownika do czasu ich usunięcia, przeniesienia, wyczyszczenia danych aplikacji albo odinstalowania aplikacji, zależnie od miejsca zapisania pliku.

Lokalne dane kolejki, transferu, trialu, języka i uprawnienia mogą pozostać na urządzeniu tak długo, jak jest to potrzebne do działania aplikacji. Użytkownik może usunąć lokalne dane aplikacji w ustawieniach systemu Android lub przez odinstalowanie aplikacji.

10. Udostępnianie plików użytkownika

FILE 2 WATCH przesyła pliki wyłącznie w wyniku działań zainicjowanych przez użytkownika pomiędzy wybranymi przez niego urządzeniami. Do zwykłego transferu plików aplikacja nie wymaga tworzenia konta FILE 2 WATCH u dewelopera.

Dostawcy platform, tacy jak Google, mogą niezależnie przetwarzać informacje techniczne, informacje o koncie, bezpieczeństwie, instalacji, synchronizacji lub transakcji podczas świadczenia usług Android, Wear OS, Google Play services lub Google Play Billing. Takie przetwarzanie podlega zasadom i politykom prywatności Google.

11. Dzieci

FILE 2 WATCH jest ogólnym narzędziem do przesyłania plików i nie jest zaprojektowany do gromadzenia danych osobowych dzieci. Nie należy przesyłać poufnych danych bez upewnienia się, że urządzenie docelowe i sieć są zaufane.

12. Bezpieczeństwo

Aplikacja korzysta z mechanizmów komunikacyjnych platformy i kontroli integralności plików w ramach procesu transferu. Żadna metoda elektronicznego przechowywania ani bezprzewodowej komunikacji nie może zagwarantować pełnego bezpieczeństwa, dlatego należy korzystać z zaufanych urządzeń i sieci.

13. Zmiany polityki

Polityka może zostać zaktualizowana, jeśli zmienią się funkcje FILE 2 WATCH, uprawnienia, usługi platformy, sposób obsługi zakupów lub wymagania prawne. Aktualna wersja będzie publikowana pod tym adresem z nową datą aktualizacji.

14. Kontakt

W sprawach dotyczących prywatności FILE 2 WATCH należy użyć oficjalnych danych kontaktowych dewelopera podanych w Google Play lub na oficjalnej stronie: https://lukaszednarski998.github.io/privacy-policy.html/.
