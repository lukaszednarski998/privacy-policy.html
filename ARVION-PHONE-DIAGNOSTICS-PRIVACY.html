Privacy Policy – ARVION Phone Diagnostics

Effective date: 3 September 2026
Package name: com.aplikacjeandroid.arvionphonediagnostics

Privacy summary: ARVION Phone Diagnostics is designed to work offline. The application does not include the Android INTERNET permission, does not require an account, does not contain advertising SDKs, and does not send diagnostic results to a developer-operated server.
English

1. Scope

This Privacy Policy explains how ARVION Phone Diagnostics handles information while providing device diagnostics, performance tests, history, and performance-recovery tools on Android.

2. Personal data and accounts

The application does not require registration or a user account. The developer does not collect, sell, rent, or use personal data for advertising, marketing, profiling, or behavioral tracking.

The application does not include third-party advertising SDKs or developer-operated analytics services.

3. Offline operation and network access

ARVION Phone Diagnostics does not request the Android INTERNET permission. Device-health information, benchmark results, preferences, and history are processed locally on the user's device and are not uploaded by the application to a developer-operated cloud server.

4. Device diagnostic information

To provide its core functions, the application may locally read or calculate technical information about the device, including:

  • internal storage capacity, used space, and free space;
  • available and total RAM, memory pressure, and Android low-memory state;
  • battery level, charging state, and battery temperature when available;
  • Android thermal status and possible performance throttling indicators;
  • device uptime, Android version, CPU/core information, and security-patch information;
  • CPU benchmark completion time;
  • RAM copy throughput;
  • temporary internal-storage read/write benchmark throughput.

This information is used only to display diagnostics, calculate device-health/performance results, show recommendations, and maintain the local history selected by the user.

5. Temporary benchmark files

Storage performance tests may create a temporary benchmark file in the application's private cache directory. The file is used only for the requested read/write test and is deleted after the benchmark. The application does not use this test to read the user's personal documents, photos, videos, or other private files.

6. Optional Usage Access

The application can offer an optional feature that uses Android Usage Access (PACKAGE_USAGE_STATS) after the user explicitly enables this access in Android system settings.

If enabled, ARVION Phone Diagnostics may read recent usage statistics for installed user applications, such as package name, application label, recent foreground-use time, and last-used time. This is used locally to help identify recently active applications and to guide the user to relevant Android management screens.

Per-app usage information is not uploaded to the developer and is not stored in the application's diagnostic/benchmark history. Users may revoke Usage Access at any time in Android settings.

7. Background-process control on older Android versions

On Android 13 and earlier, the application declares KILL_BACKGROUND_PROCESSES with a maximum SDK level of 33. When the user initiates a compatible performance-recovery action, Android may allow the application to request termination of eligible cached/background user-app processes. Android remains in control of whether a process is actually stopped.

On newer Android versions, third-party applications are restricted from terminating other applications in this way. ARVION Phone Diagnostics does not claim to bypass Android security restrictions.

8. Cache cleanup and performance recovery

The application can clear only its own temporary cache files. It does not silently delete another application's data, messages, photos, documents, or account information.

Other optimization actions may open official Android, storage-management, battery, application-management, or compatible manufacturer device-care screens. Actions completed in those system screens are controlled by Android or the device manufacturer.

9. Local settings and history

The application may store local preferences such as selected language and automatic-scan settings. It may also store a limited local history of diagnostic and performance-test summaries, including timestamps, scores, and technical result summaries.

This local information remains in the application's private storage. Users can clear test history in the application where the option is available, clear application data through Android settings, or remove it by uninstalling the application.

10. Data sharing and third parties

The developer does not sell or share application diagnostic data with third parties for advertising, marketing, or profiling. The application does not transmit its locally generated diagnostic history to a developer-operated server.

When the application opens an Android or manufacturer system-settings screen, that screen is provided by the operating system or device manufacturer and is governed by their own terms and privacy practices.

11. Advertising and subscriptions

ARVION Phone Diagnostics does not display third-party advertising and does not include advertising trackers. The application does not require a recurring subscription to perform the functions described in this policy.

12. Children

The application is a general device-utility tool and is not designed to knowingly collect personal information from children. It does not operate a developer-hosted account or profile database.

13. Security

The application is designed to keep its diagnostic processing and stored history on the user's device. Users should keep Android and device security updates current and should review optional permissions before enabling them.

14. User choices

Optional Usage Access can be enabled or disabled in Android system settings. Local history can be cleared from the application where supported, and all local application data can be removed through Android settings or by uninstalling the application.

15. Changes to this Privacy Policy

This Privacy Policy may be updated when application functionality, Android requirements, Google Play requirements, or applicable law changes. The current version will remain available at this public address.

Polski

1. Zakres polityki

Niniejsza Polityka Prywatności wyjaśnia, w jaki sposób aplikacja ARVION Phone Diagnostics przetwarza informacje podczas diagnostyki urządzenia, testów wydajności, prowadzenia historii oraz korzystania z narzędzi odzyskiwania wydajności w systemie Android.

2. Dane osobowe i konta

Aplikacja nie wymaga rejestracji ani konta użytkownika. Deweloper nie zbiera, nie sprzedaje, nie wynajmuje i nie wykorzystuje danych osobowych do reklam, marketingu, profilowania ani śledzenia zachowania użytkownika.

Aplikacja nie zawiera zewnętrznych bibliotek reklamowych ani systemu analitycznego obsługiwanego przez dewelopera.

3. Działanie offline i dostęp do Internetu

ARVION Phone Diagnostics nie żąda uprawnienia Android INTERNET. Informacje diagnostyczne, wyniki testów, ustawienia i historia są przetwarzane lokalnie na urządzeniu użytkownika i nie są przesyłane przez aplikację na serwer dewelopera.

4. Informacje diagnostyczne urządzenia

W celu realizacji podstawowych funkcji aplikacja może lokalnie odczytywać lub obliczać informacje techniczne, w tym:

  • pojemność pamięci wewnętrznej, zajęte i wolne miejsce;
  • dostępną i całkowitą pamięć RAM oraz sygnał niskiej pamięci Android;
  • poziom baterii, stan ładowania i temperaturę baterii, jeżeli jest dostępna;
  • stan termiczny Androida i możliwe ograniczanie wydajności;
  • czas działania urządzenia, wersję Androida, informacje o CPU/rdzeniach i poprawkach bezpieczeństwa;
  • czas wykonania testu CPU;
  • przepustowość kopiowania pamięci RAM;
  • prędkość zapisu i odczytu tymczasowego pliku testowego w pamięci wewnętrznej.

Dane te służą wyłącznie do wyświetlania diagnostyki, obliczania wyników kondycji i wydajności, przedstawiania zaleceń oraz prowadzenia lokalnej historii.

5. Tymczasowe pliki testowe

Test pamięci masowej może utworzyć tymczasowy plik testowy w prywatnym katalogu cache aplikacji. Plik służy wyłącznie do testu zapisu i odczytu i jest usuwany po zakończeniu testu. Aplikacja nie wykorzystuje tego testu do odczytywania prywatnych dokumentów, zdjęć, filmów ani innych plików użytkownika.

6. Opcjonalny Dostęp do danych o użyciu

Aplikacja może korzystać z opcjonalnego dostępu Android do danych o użyciu (PACKAGE_USAGE_STATS) dopiero po jego świadomym włączeniu przez użytkownika w ustawieniach systemowych.

Po włączeniu aplikacja może lokalnie odczytać informacje o ostatnim użyciu aplikacji użytkownika, takie jak nazwa pakietu, nazwa aplikacji, czas użycia na pierwszym planie oraz czas ostatniego użycia. Funkcja służy do wskazywania ostatnio aktywnych aplikacji i prowadzenia użytkownika do odpowiednich ekranów zarządzania Androida.

Dane o użyciu poszczególnych aplikacji nie są przesyłane do dewelopera i nie są zapisywane w historii diagnostyki ani benchmarków. Dostęp można w każdej chwili wyłączyć w ustawieniach Androida.

7. Kontrola procesów w starszych wersjach Androida

W Androidzie 13 i starszym aplikacja deklaruje KILL_BACKGROUND_PROCESSES wyłącznie do poziomu SDK 33. Po ręcznym uruchomieniu zgodnej funkcji odzyskiwania wydajności Android może pozwolić aplikacji zażądać zakończenia wybranych procesów użytkownika znajdujących się w tle lub pamięci podręcznej. Ostateczną decyzję o zatrzymaniu procesu podejmuje system Android.

W nowszych wersjach Android ogranicza aplikacjom zewnętrznym możliwość kończenia procesów innych aplikacji. ARVION Phone Diagnostics nie omija zabezpieczeń systemowych.

8. Czyszczenie cache i odzyskiwanie wydajności

Aplikacja może usuwać wyłącznie własne tymczasowe pliki cache. Nie usuwa po cichu danych innych aplikacji, wiadomości, zdjęć, dokumentów ani informacji o kontach.

Pozostałe działania optymalizacyjne mogą otwierać oficjalne ekrany Androida, menedżera pamięci, ustawień baterii, zarządzania aplikacjami lub zgodne narzędzia producenta urządzenia. Działania wykonywane na tych ekranach są kontrolowane przez Androida lub producenta telefonu.

9. Ustawienia lokalne i historia

Aplikacja może lokalnie przechowywać ustawienia, takie jak wybrany język i opcja automatycznego skanowania. Może również przechowywać ograniczoną historię wyników diagnostyki i testów wydajności, w tym czas testu, wynik punktowy i techniczne podsumowanie pomiarów.

Dane te pozostają w prywatnej pamięci aplikacji. Użytkownik może usunąć historię w aplikacji, wyczyścić dane aplikacji w ustawieniach Androida lub usunąć je poprzez odinstalowanie aplikacji.

10. Udostępnianie danych i usługi zewnętrzne

Deweloper nie sprzedaje ani nie udostępnia danych diagnostycznych podmiotom trzecim w celach reklamowych, marketingowych lub profilowania. Aplikacja nie wysyła lokalnej historii diagnostycznej na serwer dewelopera.

Jeżeli aplikacja otwiera ekran ustawień Androida lub narzędzie producenta telefonu, taki ekran jest dostarczany przez system operacyjny lub producenta urządzenia i podlega ich własnym zasadom prywatności.

11. Reklamy i subskrypcje

ARVION Phone Diagnostics nie wyświetla reklam podmiotów trzecich i nie zawiera trackerów reklamowych. Aplikacja nie wymaga cyklicznej subskrypcji do korzystania z funkcji opisanych w tej polityce.

12. Dzieci

Aplikacja jest ogólnym narzędziem diagnostycznym urządzenia i nie została zaprojektowana do świadomego zbierania danych osobowych dzieci. Nie prowadzi systemu kont ani bazy profili użytkowników na serwerze dewelopera.

13. Bezpieczeństwo

Aplikacja została zaprojektowana tak, aby przetwarzanie diagnostyczne i historia pozostawały na urządzeniu użytkownika. Zalecane jest aktualizowanie Androida i poprawek bezpieczeństwa oraz świadome zarządzanie opcjonalnymi uprawnieniami.

14. Wybory użytkownika

Opcjonalny dostęp do danych o użyciu można włączyć lub wyłączyć w ustawieniach Androida. Historię lokalną można usunąć w aplikacji, a wszystkie dane lokalne można skasować z poziomu ustawień Androida lub przez odinstalowanie aplikacji.

15. Zmiany Polityki Prywatności

Polityka może być aktualizowana wraz ze zmianami funkcji aplikacji, wymagań Androida, Google Play lub obowiązujących przepisów. Aktualna wersja pozostanie dostępna pod tym publicznym adresem.
