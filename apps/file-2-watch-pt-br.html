FILE 2 WATCH — Transferências e gerenciamento de arquivos para Wear OS

FILE 2 WATCH foi projetado para ajudá-lo a mover arquivos selecionados de um telefone Android para um relógio Wear OS compatível, gerenciar arquivos armazenados no relógio e abrir formatos suportados.

Funcionalidade planejada

  • Escolha arquivos ou pastas individuais no telefone Android
  • Transfira arquivos para um smartwatch Wear OS compatível
  • Navegue e organize os arquivos transferidos no relógio
  • Abra tipos de arquivos de imagem, documentos e mídia suportados
  • Envie os arquivos selecionados do relógio de volta para o telefone

Compatibilidade do dispositivo

Os métodos de transferência e formatos de arquivo suportados dependem do telefone, do relógio e da conexão disponível.

Informações sobre a Polônia

Planowana aplikacja do przesyłania plików między phonem Android e zegarkiem Wear OS oraz zarządzania plikami na zegarku.

W przygotowaniu. Aplikacja nie jest jeszcze dostępna do pobrania.
