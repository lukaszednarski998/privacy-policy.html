NOTE VAULT PRO

Catatan pribadi Android dan Wear OS dengan enkripsi, tulisan, OCR, sinkronisasi.

Segera hadir

NOTE VAULT PRO adalah aplikasi catatan lengkap untuk Android yang dirancang untuk menyimpan data terutama di perangkat. Catatan disimpan di perangkat dan Anda tidak memerlukan akun untuk menggunakan aplikasi.

Buat catatan biasa, daftar periksa, tabel, blok kode, dan rumus LaTeX. Tambahkan gambar, dokumen PDF, rekaman, dan lampiran lainnya. Menulis dengan pena, pensil, penyorot, penghapus, bentuk, penggaris, segitiga, dan laso. Pengenalan tulisan tangan, OCR dokumen, dan dikte lokal membantu mengubah konten menjadi teks lebih cepat. Ketersediaan pengenalan suara bergantung pada perangkat, versi Android, dan bahasa yang terpasang.

PENGATURAN DAN AKSES CEPAT
• folder dan subfolder, tag, catatan yang disematkan, favorit, dan arsip,
• folder pintar dan pengurutan,
• pencarian dalam judul, isi, folder, dan tag,
• tautan antarcatatan dan tautan balik,
• riwayat versi, penyimpanan otomatis, draf, dan Sampah,
• tab catatan terbaru, pratinjau tablet, dan widget catatan pilihan,
• tindakan cepat untuk catatan, daftar periksa, pemindaian, rekaman, dan tulisan tangan.

PRIVASI DAN PERLINDUNGAN
Lindungi catatan pilihan dan lampiran yang didukung dengan enkripsi AES-GCM. Aplikasi menyediakan PIN, autentikasi biometrik, dan kunci aplikasi penuh. Pencarian isi catatan yang dilindungi tersedia setelah autentikasi dan berjalan di memori sesi saat ini.

PENGINGAT
Atur pengingat satu kali, harian, mingguan, bulanan, atau hanya pada hari kerja. Notifikasi dapat ditunda selama 10 menit atau ditandai selesai.

IMPOR, EKSPOR, DAN PDF
Impor catatan dan file, bagikan teks beserta lampiran, lalu ekspor ke TXT, Markdown, PDF, HTML, dan DOCX. Tambahkan anotasi vektor tulisan tangan ke PDF yang ada tanpa mengubah seluruh halaman menjadi gambar. Web Clipper menyimpan teks halaman HTTPS pilihan beserta sumbernya.

CADANGAN DAN SINKRONISASI
Buat cadangan manual atau otomatis. Sync PRO menyinkronkan catatan melalui folder yang dipilih dengan pemilih sistem Android. Folder ini dapat berupa folder lokal atau folder dari penyedia cloud yang didukung dan terlihat di pemilih file sistem. Cadangan otomatis dan sinkronisasi dilindungi kata sandi. Aplikasi tidak mengoperasikan layanan cloud sendiri.

PONSEL + WEAR OS
Hubungkan aplikasi ke jam Wear OS yang kompatibel. Catatan disinkronkan otomatis, dan tombol Sinkronkan juga dapat memulai proses secara manual. Bilah progres berakhir dengan tanda centang hijau setelah jam mengonfirmasi penerimaan. Di jam, Anda dapat melihat catatan, membuat dan mengedit teks, mengubah status sematkan, favorit, arsip dan perlindungan, serta bekerja offline. Isi dan data organisasi disinkronkan; perubahan bersamaan disimpan sebagai salinan konflik. Detail lampiran terlihat di jam dan file dapat diunduh sesuai permintaan.

NOTE VAULT PRO tidak berisi iklan. Fitur jaringan digunakan untuk sinkronisasi, pengunduhan model pengenalan, pembelian Google Play, atau saat Anda menjalankan Web Clipper.
