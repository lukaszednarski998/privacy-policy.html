NOTE VAULT PRO

暗号化、手書き、OCR、同期に対応した Android／Wear OS 用プライベートノート。

近日公開

NOTE VAULT PRO は、端末内の保存を中心に設計された Android 用の多機能ノートアプリです。ノートは端末に保存され、利用にアカウントは必要ありません。

通常のノート、チェックリスト、表、コードブロック、LaTeX 数式を作成できます。画像、PDF、録音、その他の添付ファイルにも対応しています。ペン、鉛筆、蛍光ペン、消しゴム、図形、定規、三角定規、投げ縄を使って手書きできます。手書き認識、文書 OCR、端末上の音声入力により、内容をすばやくテキスト化できます。音声認識の利用可否は、端末、Android のバージョン、インストール済み言語によって異なります。

整理とクイックアクセス
• フォルダーとサブフォルダー、タグ、ピン留め、お気に入り、アーカイブ
• スマートフォルダーと並べ替え
• タイトル、本文、フォルダー、タグの検索
• ノート間リンクとバックリンク
• バージョン履歴、自動保存、下書き、ゴミ箱
• 最近のノートのタブ、タブレット表示、選択したノートのウィジェット
• ノート、チェックリスト、スキャン、録音、手書きのクイック操作

プライバシーと保護
選択したノートと対応する添付ファイルを AES-GCM で暗号化できます。PIN、生体認証、アプリ全体のロックに対応しています。保護されたノートの本文検索は認証後に利用でき、現在のセッションのメモリ上で実行されます。

リマインダー
1 回、毎日、毎週、毎月、平日のみのリマインダーを設定できます。通知は 10 分間スヌーズするか、完了として処理できます。

インポート、エクスポート、PDF
ノートやファイルをインポートし、添付ファイル付きでテキストを共有できます。TXT、Markdown、PDF、HTML、DOCX にエクスポートできます。既存の PDF 全体を画像化せず、手書きのベクター注釈を追加できます。Web Clipper は、指定した HTTPS ページのテキストを参照元とともに保存します。

バックアップと同期
手動または自動でバックアップできます。Sync PRO は Android のシステム選択画面で指定したフォルダーを通してノートを同期します。ローカルフォルダーのほか、システムのファイル選択画面に表示される対応クラウド事業者のフォルダーを利用できます。自動バックアップと同期はパスワードで保護されます。このアプリは独自のクラウドサービスを運営しません。

スマートフォン + WEAR OS
対応する Wear OS ウォッチと接続できます。ノートは自動同期され、同期ボタンから手動でも開始できます。ウォッチが受信を確認すると、進捗バーは緑のチェックで完了します。ウォッチではノートの閲覧、テキストの作成と編集、固定・お気に入り・アーカイブ・保護状態の変更、オフライン作業ができます。ノート内容と整理情報が同期され、同時変更は競合コピーとして保持されます。添付ファイルの情報を確認し、必要なファイルだけをダウンロードできます。

NOTE VAULT PRO には広告がありません。ネットワーク機能は、同期、認識モデルのダウンロード、Google Play での購入、または Web Clipper の起動時に使用されます。
