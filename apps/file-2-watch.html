FILE 2 WATCH — File transfers and file management for Wear OS

FILE 2 WATCH is designed to help you move selected files from an Android phone to a compatible Wear OS watch, manage stored files on the watch and open supported formats.

COMING SOON — this app is not available to download yet.

Planned functionality

  • Choose individual files or folders on the Android phone
  • Transfer files to a compatible Wear OS smartwatch
  • Browse and organize transferred files on the watch
  • Open supported image, document and media file types
  • Send selected files from the watch back to the phone

Device compatibility

Transfer methods and supported file formats depend on the phone, watch and available connection.
