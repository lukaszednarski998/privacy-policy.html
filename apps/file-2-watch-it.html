FILE 2 WATCH: trasferimenti e gestione dei file per Wear OS

FILE 2 WATCH è progettato per aiutarti a spostare i file selezionati da un telefono Android a un orologio Wear OS compatibile, gestire i file memorizzati sull'orologio e aprire i formati supportati.

PROSSIMAMENTE: questa app non è ancora disponibile per il download.

Funzionalità pianificata

  • Scegli singoli file o cartelle sul telefono Android
  • Trasferisci file su uno smartwatch Wear OS compatibile
  • Sfoglia e organizza i file trasferiti sull'orologio
  • Apri tipi di file multimediali, immagini e documenti supportati
  • Invia i file selezionati dall'orologio al telefono

Compatibilità del dispositivo

I metodi di trasferimento e i formati di file supportati dipendono dal telefono, dall'orologio e dalla connessione disponibile.

Informazioni sul paese

Planowana aplikacja do przesyłania plików między telefonem Android a zegarkiem Wear OS oraz zarządzania plikami na zegarku.

W przygotowaniu. L'applicazione non è disponibile solo per la pobrania.
