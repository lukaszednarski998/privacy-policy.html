FILE 2 WATCH — Wear OS のファイル転送とファイル管理

FILE 2 WATCH は、選択したファイルを Android 携帯電話から互換性のある Wear OS ウォッチに移動したり、ウォッチに保存されているファイルを管理したり、サポートされている形式を開いたりできるように設計されています。

近日公開予定 — このアプリはまだダウンロードできません。

計画された機能

  • Android 電話機で個々のファイルまたはフォルダーを選択します
  • 互換性のあるWear OSスマートウォッチにファイルを転送します
  • 転送されたファイルをウォッチ上で参照および整理する
  • サポートされている画像、ドキュメント、メディア ファイル タイプを開く
  • 選択したファイルを時計から携帯電話に送り返す

デバイスの互換性

転送方法とサポートされるファイル形式は、携帯電話、時計、利用可能な接続によって異なります。
