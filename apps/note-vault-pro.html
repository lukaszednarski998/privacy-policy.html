NOTE VAULT PRO

Private notes with handwriting, encryption and Wear OS sync.

Coming soon

NOTE VAULT PRO is a private, feature-rich notebook for Android with support for Wear OS. Notes are stored on your device, and no account is required to use the app.

Create and edit notes
Create notes, checklists, tables, code blocks and LaTeX formulas. Add images, PDF documents, audio recordings and other attachments. Write by hand using a pen, pencil, highlighter, eraser, shapes, ruler, triangle and lasso.

Handwriting recognition, document OCR and local dictation help convert content into text. Speech recognition availability depends on the device, Android version and installed language.

Organize your notes
- Folders, subfolders, tags, pinned notes, favorites and archive
- Smart folders and sorting
- Search through titles, content, folders and tags
- Links between notes and backlinks
- Version history, autosave, drafts and Trash
- Recent note tabs, tablet view and a selected-note widget
- Quick actions for notes, checklists, scans, recordings and handwriting

Privacy and protection
Protect selected notes and supported attachments using AES-GCM encryption. Use a PIN, biometric authentication and an app lock. Searching protected notes is available after authentication and runs in memory during the current session.

Reminders
Schedule one-time, daily, weekly, monthly or weekday reminders. Snooze a reminder for 10 minutes or mark it as complete.

Import, export and PDF
Import notes and files, share text with attachments, and export to TXT, Markdown, PDF, HTML or DOCX. Add handwritten vector annotations to existing PDF documents without converting the entire page into an image. Web Clipper saves the text of a selected HTTPS page along with its source.

Backups and Sync PRO
Create manual or automatic backups. Sync PRO synchronizes notes through a folder selected in the Android system file picker. This can be a local folder or one made available by a supported cloud provider. Automatic backups and synchronization are password-protected. The app does not provide its own cloud service.

Phone and Wear OS
Connect NOTE VAULT PRO to a compatible Wear OS watch. Notes sync automatically, or you can start synchronization with the Sync button. When the watch confirms receipt, the progress bar shows a green check mark.

On your watch, browse notes, create and edit text, manage pinned notes, favorites, archived items and protection, and work offline. Note content and organizational data are synchronized. Concurrent edits are preserved as conflict copies. Attachment details are displayed on the watch, and files can be downloaded on demand.

NOTE VAULT PRO contains no ads. Network features are used for synchronization, recognition-model downloads, Google Play purchases and Web Clipper when you choose to use them.
