Kids Time est une application simple de contrôle parental et de gestion du temps d’écran pour limiter la durée d’utilisation d’un téléphone ou d’une tablette Android par un enfant.

Elle s’adresse aux parents qui veulent définir une limite quotidienne claire sans menus compliqués, compte, synchronisation ni dizaines d’options inutiles.

CONFIGURATION SIMPLE

  • Définissez un code PIN parent
  • Choisissez une limite quotidienne de temps d’écran
  • Activez la protection
  • Terminé

Kids Time compte automatiquement le temps d’utilisation lorsque l’écran est allumé. Il n’est pas nécessaire de lancer l’application manuellement à chaque utilisation.

LIMITE QUOTIDIENNE DE TEMPS D’ÉCRAN

Choisissez combien de temps votre enfant peut utiliser le téléphone ou la tablette chaque jour. Kids Time surveille automatiquement le temps quotidien.

Lorsque la limite est atteinte, l’écran de blocage Kids Time apparaît. Un parent peut saisir le PIN et ajouter du temps supplémentaire si nécessaire.

PROTECTION PAR PIN PARENT

Le PIN principal protège l’accès aux réglages. Un PIN d’urgence est également disponible si le code principal est oublié.

Après trois tentatives de PIN incorrectes, Kids Time peut déclencher une alarme.

FONCTIONS PRINCIPALES

  • Contrôle parental simple
  • Limite quotidienne de temps d’écran
  • Comptage automatique du temps
  • Temps compté uniquement lorsque l’écran est allumé
  • Blocage automatique à la fin du temps autorisé
  • Temps supplémentaire contrôlé par le parent
  • PIN parent principal
  • PIN d’urgence
  • Alarme après trois PIN incorrects
  • Protection contre la suppression accidentelle de l’application
  • Les appels restent disponibles après la limite
  • Les SMS restent disponibles après la limite
  • Interface disponible en 14 langues

UN CONTRÔLE PARENTAL SANS COMPLICATION

Kids Time se concentre sur un objectif : aider les parents à décider combien de temps un enfant peut utiliser un téléphone ou une tablette.

Pas de menus compliqués. Pas de fonctions inutiles. Aucun compte ni synchronisation requis.

Définissez le PIN. Définissez le temps. Terminé.
