Kids Time est une application simple de contrôle parental et de temps d'écran permettant de gérer la durée pendant laquelle un enfant peut utiliser un téléphone ou une tablette Android.

Il est conçu pour les parents qui souhaitent des limites claires de temps d'écran quotidien sans menus, comptes, synchronisation ou dizaines d'options compliquées.

CONFIGURER LE TEMPS DES ENFANTS EST SIMPLE

  • Définir un code PIN parent
  • Choisissez une limite quotidienne de temps d'écran
  • Activer la protection
  • Terminé

Kids Time compte automatiquement le temps d'écran lorsque l'écran est allumé. Vous n'avez pas besoin d'ouvrir ou de démarrer l'application manuellement à chaque fois que l'appareil est utilisé.

LIMITE DE TEMPS D'ÉCRAN DAILY

Choisissez combien de temps votre enfant peut utiliser le téléphone ou la tablette chaque jour. Kids Time surveille automatiquement la durée d'utilisation quotidienne.

Lorsque la limite quotidienne est atteinte, l'écran de blocage Kids Time apparaît. Un parent peut saisir le code PIN et ajouter du temps supplémentaire si nécessaire.

PROTECTION DU NIP PARENT

Le code PIN parent principal protège l’accès aux paramètres. Un code PIN d'urgence est également disponible en cas d'oubli du code PIN principal.

Après trois tentatives de code PIN incorrectes, Kids Time peut déclencher une alarme pour alerter le parent.

CARACTÉRISTIQUES DU MAIN

  • Configuration simple du contrôle parental
  • Limite quotidienne de temps d'écran
  • Comptage automatique du temps
  • Compte le temps uniquement lorsque l'écran est allumé
  • Blocage automatique lorsque la limite est atteinte
  • Temps supplémentaire contrôlé par les parents
  • Code PIN parent principal
  • Code PIN d'urgence
  • Alarme après trois tentatives de code PIN incorrectes
  • Protection contre la suppression accidentelle d'applications
  • Les appels téléphoniques restent disponibles après la limite de temps
  • Le SMS reste disponible après le délai
  • Interface disponible en 14 langues

CONTRÔLE PARENTAL SIMPLE

Kids Time se concentre sur un seul objectif : aider les parents à décider combien de temps un enfant peut utiliser un téléphone ou une tablette.

Pas de menus compliqués. Aucune fonctionnalité inutile. Aucun compte ni synchronisation requis.

Vous n'avez pas besoin d'être un expert du Android. Kids Time vous guide étape par étape tout au long de la configuration requise.
