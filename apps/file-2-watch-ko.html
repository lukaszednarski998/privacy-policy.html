FILE 2 WATCH — Wear OS의 파일 전송 및 파일 관리

FILE 2 WATCH는 Android 휴대폰에서 호환되는 Wear OS 시계로 선택한 파일을 이동하고, 시계에 저장된 파일을 관리하고, 지원되는 형식을 열 수 있도록 설계되었습니다.

계획된 기능

  • Android 전화기에서 개별 파일 또는 폴더 선택
  • 호환되는 Wear OS 스마트워치로 파일 전송
  • 시계에서 전송된 파일을 찾아보고 정리하세요.
  • 지원되는 이미지, 문서 및 미디어 파일 형식 열기
  • 시계에서 선택한 파일을 휴대폰으로 다시 보내기

장치 호환성

전송 방법과 지원되는 파일 형식은 휴대폰, 시계 및 사용 가능한 연결에 따라 다릅니다.
