KIDS REMOTE LOCK — Parental controls, screen-time limits and remote lock

KIDS REMOTE LOCK is being developed as a parental-control tool with parent-managed device locking, screen-time limits and schedules for supported devices.

COMING SOON — this app is not available to download yet.

Planned functionality

  • Set screen-time rules for a child's supported device
  • Create schedules and daily usage limits
  • Manage app blocking and device lock settings
  • Use parent-managed protection and pairing
  • Control supported child-device access from a parent device

Device compatibility

Availability and support for individual Android versions or other platforms will be confirmed before release.
