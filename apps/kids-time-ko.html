Kids Time은 자녀가 Android 휴대폰이나 태블릿을 사용할 수 있는 시간을 부모가 간단하게 정할 수 있는 자녀 보호 및 화면 시간 관리 앱입니다.

복잡한 메뉴, 계정, 동기화, 수많은 옵션 없이 명확한 일일 화면 시간 제한을 원하는 부모를 위해 설계되었습니다.

간단한 설정

  • 부모 PIN 설정
  • 일일 화면 시간 제한 선택
  • 보호 기능 활성화
  • 완료

Kids Time은 화면이 켜져 있는 동안 사용 시간을 자동으로 계산합니다. 기기를 사용할 때마다 앱을 직접 실행할 필요가 없습니다.

일일 화면 시간 제한

자녀가 하루 동안 휴대폰이나 태블릿을 사용할 수 있는 시간을 설정하세요. Kids Time이 일일 사용 시간을 자동으로 모니터링합니다.

제한 시간이 끝나면 Kids Time 차단 화면이 표시됩니다. 필요한 경우 부모가 PIN을 입력해 추가 시간을 줄 수 있습니다.

부모 PIN 보호

기본 부모 PIN으로 설정 화면을 보호합니다. 기본 PIN을 잊어버린 경우를 위한 비상 PIN도 사용할 수 있습니다.

PIN을 세 번 잘못 입력하면 Kids Time이 알람을 실행할 수 있습니다.

주요 기능

  • 간단한 자녀 보호 설정
  • 일일 화면 시간 제한
  • 자동 사용 시간 계산
  • 화면이 켜져 있을 때만 시간 계산
  • 제한 시간 도달 시 자동 차단
  • 부모가 관리하는 추가 시간
  • 기본 부모 PIN
  • 비상 PIN
  • PIN 3회 오류 후 알람
  • 실수로 앱이 삭제되는 것을 방지하는 보호 기능
  • 제한 시간 이후에도 전화 사용 가능
  • 제한 시간 이후에도 SMS 사용 가능
  • 14개 언어 인터페이스

간단한 자녀 보호

Kids Time은 한 가지 목표에 집중합니다. 부모가 자녀의 휴대폰 또는 태블릿 사용 시간을 쉽게 결정할 수 있도록 돕는 것입니다.

복잡한 메뉴나 불필요한 기능이 없습니다. 계정이나 동기화도 필요하지 않습니다.
