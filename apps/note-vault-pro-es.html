NOTE VAULT PRO

Notas privadas para Android y Wear OS con cifrado y sincronización.

Próximamente

NOTE VAULT PRO es un cuaderno completo para Android diseñado para guardar los datos primero en el dispositivo. Las notas se almacenan en el dispositivo y no necesitas una cuenta para usar la aplicación.

Crea notas, listas de tareas, tablas, bloques de código y fórmulas LaTeX. Añade imágenes, documentos PDF, grabaciones y otros archivos adjuntos. Escribe a mano con bolígrafo, lápiz o marcador y utiliza borrador, formas, regla, triángulo y lazo. El reconocimiento de escritura, el OCR de documentos y el dictado local ayudan a convertir el contenido en texto. La disponibilidad del reconocimiento de voz depende del dispositivo, la versión de Android y el idioma instalado.

ORGANIZACIÓN Y ACCESO RÁPIDO
• carpetas y subcarpetas, etiquetas, notas fijadas, favoritos y archivo,
• carpetas inteligentes y ordenación,
• búsqueda en títulos, contenido, carpetas y etiquetas,
• enlaces entre notas y enlaces de retorno,
• historial de versiones, guardado automático, borradores y Papelera,
• pestañas de notas recientes, vista para tablet y widget de nota,
• acciones rápidas para notas, listas, escaneos, grabaciones y escritura.

PRIVACIDAD Y PROTECCIÓN
Protege las notas seleccionadas y los adjuntos compatibles mediante cifrado AES-GCM. La aplicación ofrece PIN, autenticación biométrica y bloqueo completo. La búsqueda en notas protegidas está disponible después de autenticarte y se realiza en la memoria de la sesión actual.

RECORDATORIOS
Configura recordatorios únicos, diarios, semanales, mensuales o solo para días laborables. Puedes aplazar una notificación 10 minutos o marcarla como completada.

IMPORTACIÓN, EXPORTACIÓN Y PDF
Importa notas y archivos, comparte texto con adjuntos y exporta a TXT, Markdown, PDF, HTML y DOCX. Añade anotaciones manuscritas vectoriales a documentos PDF existentes sin convertir toda la página en una imagen. Web Clipper guarda el texto de una página HTTPS seleccionada junto con su fuente.

COPIA DE SEGURIDAD Y SINCRONIZACIÓN
Crea copias manuales o automáticas. Sync PRO sincroniza las notas mediante una carpeta seleccionada con el selector de Android. Puede ser una carpeta local o una carpeta ofrecida por un proveedor de nube compatible visible en el selector del sistema. Las copias automáticas y la sincronización están protegidas con contraseña. La aplicación no gestiona un servicio de nube propio.

TELÉFONO + WEAR OS
Conecta la aplicación a un reloj Wear OS compatible. Las notas se sincronizan automáticamente y el botón Sincronizar también permite iniciar el proceso manualmente. La barra de progreso termina con una marca verde cuando el reloj confirma la recepción. En el reloj puedes consultar notas, crear y editar texto, cambiar los estados fijada, favorita, archivada y protegida, y trabajar sin conexión. Se sincronizan el contenido y los datos de organización; los cambios simultáneos se conservan como copia en conflicto. Los datos de los adjuntos aparecen en el reloj y los archivos se descargan bajo demanda.

NOTE VAULT PRO no contiene anuncios. Las funciones de red se utilizan para sincronizar, descargar modelos de reconocimiento, realizar compras en Google Play o iniciar Web Clipper.
