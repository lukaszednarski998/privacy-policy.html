BLOQUEO REMOTO PARA NIÑOS: controles parentales, límites de tiempo de pantalla y bloqueo remoto

KIDS REMOTE LOCK se está desarrollando como una herramienta de control parental con bloqueo de dispositivos administrado por los padres, límites de tiempo de pantalla y horarios para dispositivos compatibles.

PRÓXIMAMENTE: esta aplicación aún no está disponible para descargar.

Funcionalidad planificada

  • Establecer reglas de tiempo de pantalla para el dispositivo compatible de un niño
  • Crear horarios y límites de uso diario
  • Administrar el bloqueo de aplicaciones y la configuración de bloqueo del dispositivo
  • Utilice protección y emparejamiento administrados por los padres
  • Controlar el acceso a dispositivos secundarios admitidos desde un dispositivo principal
