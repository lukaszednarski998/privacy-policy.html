NOTE VAULT PRO

适用于 Android 和 Wear OS 的私人笔记，支持加密、手写、OCR 和同步。

即将推出

NOTE VAULT PRO 是一款以本机存储为核心的 Android 多功能笔记应用。笔记保存在设备上，使用应用无需注册账户。

你可以创建普通笔记、清单、表格、代码块和 LaTeX 公式，并添加图片、PDF 文档、录音及其他附件。手写功能提供钢笔、铅笔、荧光笔、橡皮擦、图形、直尺、三角尺和套索工具。手写识别、文档 OCR 和设备端语音输入可帮助你更快地将内容转换为文字。语音识别是否可用取决于设备、Android 版本和已安装的语言。

整理与快速访问
• 文件夹和子文件夹、标签、置顶、收藏及归档
• 智能文件夹和排序
• 搜索标题、正文、文件夹及标签
• 笔记间链接及反向链接
• 版本历史、自动保存、草稿及回收站
• 最近笔记标签页、平板预览及指定笔记小组件
• 快速创建笔记、清单、扫描、录音和手写内容

隐私与保护
可使用 AES-GCM 加密选定笔记及受支持的附件。应用支持 PIN、生物识别和整款应用锁定。通过身份验证后可搜索受保护笔记的正文，搜索仅在当前会话的内存中进行。

提醒
可设置单次、每日、每周、每月或仅工作日提醒。通知可延后 10 分钟或标记为完成。

导入、导出与 PDF
可导入笔记和文件，连同附件分享文字，并导出为 TXT、Markdown、PDF、HTML 和 DOCX。可在不将整个页面转换为图片的情况下，为现有 PDF 添加手写矢量批注。Web Clipper 会保存所选 HTTPS 网页的文字及其来源。

备份与同步
可创建手动或自动备份。Sync PRO 通过 Android 系统选择器中指定的文件夹同步笔记。该文件夹可以是本地文件夹，也可以是系统文件选择器中受支持云服务商提供的文件夹。自动备份和同步受密码保护。应用不运营自己的云服务。

手机 + WEAR OS
可连接兼容的 Wear OS 手表。笔记会自动同步，也可通过“同步”按钮手动启动。手表确认接收后，进度条以绿色对勾结束。你可以在手表上查看笔记、创建和编辑文字、更改置顶、收藏、归档和保护状态，并可离线使用。笔记内容和整理数据会同步；同时发生的修改会保留为冲突副本。手表可显示附件信息，并按需下载文件。

NOTE VAULT PRO 不含广告。网络功能用于同步、下载识别模型、Google Play 购买或用户启动 Web Clipper 时。
